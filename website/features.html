Trial experience

The base Trial License provides one automatically configured listener, five external POS jobs per local day, unlimited built-in Test Receipts, session-only activity, and a watermarked viewer. Built-in Test Receipts are identified and do not consume the daily external-job allowance.

Eligible verified customers and devices may separately request one Five-Day Promotional Trial of Lite, Pro, or Enterprise. The application displays the evaluated edition and remaining time. Reinstalling does not create another entitlement.

Paid receipt tools

Lite, Pro, and Enterprise include unlimited receipt jobs, local history, watermark-free preview, text and raw exports, print/PDF, capture/import/replay, Printer Profiles, Stored Logos, Printer State, and Copy Receipt as Image with Windows clipboard support.

Listener capacity

  • Lite: one printer listener.
  • Pro: up to two independently configured printer listeners.
  • Enterprise: up to 15 independently configured printer listeners.

Enterprise-only diagnostics

The Standard Development Diagnostics Report and Advanced Diagnostics Package require an Enterprise License. These reports can include the receipt image, command parsing, raw data, job metadata, warnings, errors, unsupported commands, listener configuration, application and environment versions, and privacy-reviewed technical details for POS developers and support teams.

Updates and support

Each new paid license includes one year of Maintenance and Support. During active coverage, customers receive eligible updates, version upgrades, technical support, update notifications, version-behind information, and applicable account and device licensing assistance. The permanent license and last eligible installed version keep working after coverage expires.
